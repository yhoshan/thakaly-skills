# مهارات ذكالي | Thakaly Skills

**مهارات رقمية مساندة للبحث العلمي في العلوم الشرعية واللغة العربية.**

مستودع مستقل لتطوير واختبار مهارات التعامل مع النصوص العربية، وتوثيق النقول، واستخراج الشواهد، وتحليل المؤلفات وتنظيم البيانات العلمية.

**الحالة:** خاص، قيد التجهيز والمراجعة. النتائج أدوات مساعدة لا تغني عن مراجعة الباحث للمصدر والسياق.

## الأقسام
- `skills/`: ملفات المهارات وشفراتها التنفيذية.
- `tests/`: إرشادات الاختبار وتقارير القبول والإخفاق.
- `registry/`: تدقيق الملفات وحالة الإصدارات.
- `governance/`: ضوابط التحقق والسلامة والمساهمة.

## المهارات الحالية
1. **مدقق المصدر والنسبة v0.2:** فاحص بنيوي وقرائن نقل، قبول مشروط؛ لا يثبت صحة النسبة تاريخيًا.
2. **كاشف منهج المؤلف v0.5:** يستخرج شواهد مرشحة للمراجعة. اختبار قبول مستقل TS-010 = **3/6**؛ غير معتمد للتكشيف الآلي الشامل.

## أولويات التجهيز
- إعادة اختبار الشفرات المسترجعة من المستودع.
- مراجعة الحقوق والأسرار والاعتماديات قبل التحويل إلى مستودع عام.
- توفير سياسة استقبال المساهمات وترخيص مناسب قبل الدعوة العامة.
