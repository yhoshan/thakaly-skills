# المرجع التقني لبنية المهارات

المرجع: https://agentskills.io/specification
أمثلة مرجعية (لا تستورد تلقائيًا): https://github.com/anthropics/skills

## المتطلبات
- مجلد لكل مهارة باسم لاتيني صغير مع الشرطات، مطابق لحقل `name`.
- `SKILL.md` يحوي YAML frontmatter مع `name` و`description` الإلزاميين.
- طول الاسم 1–64، والوصف 1–1024؛ لا تكرار للشرطات، ولا يبدأ الاسم أو ينتهي بشرطة.
- يمكن إضافة `license` و`compatibility` و`metadata`؛ `allowed-tools` تجريبي.
- `scripts/` للتنفيذ، `references/` للأدلة، `assets/` للنماذج.
- يفضل قِصَر تعليمات المهارة وإحالة التفصيل إلى المراجع النسبية.
- يمكن استخدام `skills-ref validate` عند توفر أداة التحقق.

## ضوابط ذكالي
هذه المواصفة تنظيم **تقني فقط**؛ لا تحكم مضمون معيار ذكالي، ولا تمنح دلالة علمية لكشف لفظي.
لا ترفع أي شفرات أو موارد طرف ثالث إلا بعد فحص التراخيص والاعتماديات والأسرار.
لا يدعي التوافق التشغيلي بين المنصات إلا بعد اختبارات فعلية.

المصدران أعلاه يستخدمان مرجعيًا، دون نسخ ملفات مهارات Anthropic إلى هذا المستودع.
