# برمجيات الدكتور سعود العقيل

قسم متخصص في «مهارات ذكالي» لاستلهام الوظائف العملية الواردة في دليل **«شرح برمجيات العقيل»** وتحويل ما يصلح منها إلى أدوات عربية قابلة للاختبار وإعادة الاستخدام.

**الدكتور سعود العقيل:** صاحب البرمجيات المرجعية ودليلها. لا ننقل شفراته الأصلية ولا ملفات البيانات التابعة له بغير إذن. عند كتابة تنفيذ جديد، نصرّح بأنه مستقل ومستلهم من الوظيفة.

## المهارة الأولى المختارة

[فاحص الفواصل العربية](../../skills/arabic-punctuation-auditor/) — اكتشاف استخدام الفاصلة الإنجليزية بين كلمتين عربيتين، دون مساس بالنص الأصلي. **المرحلة: وثيقة وتعليمات جاهزة؛ إيداع كود التشغيل قيد الاستكمال.**

## مهارات لاحقة في قائمة الفحص

- [كشف التشكيل المكرر](../../skills/diacritic-anomaly-auditor/)
- [مراجعة ترتيب الشدة والحركات](../../skills/arabic-diacritic-order-auditor/)
- [فحص مداخل الفهارس المكررة](../../skills/index-entry-duplicate-auditor/)
- [فحص الحواشي الفارغة](../../skills/empty-footnotes-auditor/)

**مهم:** هذه الروابط إلى بطاقات تطوير أولية، وليست شهادات جاهزية تشغيل.

## معايير القبول
- شفرة مستقلة أو إذن صريح عند استخدام شفرة صاحبها.
- وصف الوظيفة والمدخلات والمخرجات وأمثلة الاستخدام.
- اختبار نجاح واختبار إخفاق، وحماية الملف الأصلي.
- مراجعة مشرف المستودع قبل الإتاحة العامة.
