# المرجع التقني لبنية مهارات ذكالي

المواصفة: https://agentskills.io/specification
أمثلة رسمية للاسترشاد، دون استيراد تلقائي: https://github.com/anthropics/skills

## المتطلبات
- مجلد مستقل لكل مهارة باسم لاتيني صغير مع الشرطات مطابق لحقل `name`.
- `SKILL.md` يحتوي YAML frontmatter مع `name` و`description`.
- طول الاسم 1–64 والوصف 1–1024؛ لا تبدأ الأسماء أو تنتهي بشرطة.
- الحقول الإضافية الممكنة: `license` و`compatibility` و`metadata`.
- المجلدات المساعدة بحسب الحاجة: `scripts/` و`references/` و`assets/`.
- يمكن التحقق من البنية بواسطة `skills-ref validate` عند توفر الأداة.

## ضوابط التنفيذ
هذه مواصفة **لبنية المهارات التقنية**، ولا تثبت جودة النتائج العلمية.
لا ترفع الشفرات الخارجية قبل فحص التراخيص والأسرار والاعتماديات.
ولا تدّعِ قابلية تشغيلها على منصة جديدة دون اختبار فعلي.
