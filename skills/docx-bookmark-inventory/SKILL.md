# جرد الإشارات المرجعية

استخراج أسماء الإشارات المرجعية ونصوص نطاقاتها ومواضعها من DOCX دون تعديل؛ مفيد لمراجعة إحالات البحث والتنقل بين شواهده.

## طريقة العمل
1. استخدم ملف DOCX محفوظًا. ارفض DOC وDOCM وPDF؛ لا تشغّل ماكرو ولا تحوّل الأصل تلقائيًا.
2. شغّل من مجلد المهارة: `python scripts/inspect_docx.py input.docx --out report.csv`.
3. اقرأ `warnings` و`limitations` قبل عرض عدد النتائج؛ الصفر لا يثبت خلو الأجزاء غير المدعومة.
4. اعرض السجلات كما استخرجت. لا تصحح آية أو حديثًا أو اسمًا، ولا تزيل تشكيلًا أو تغيّر ترتيب حروف.
5. احتفظ ببصمة المصدر الواردة في التقرير. لا تنسب للمخرجات أرقام صفحات فعلية.

## المدخل والمخرج
المدخل DOCX بترميز OOXML القياسي الانتقالي. المخرج الافتراضي المقترح CSV جديد بترميز UTF-8 مع BOM. يقبل أيضًا امتداد JSON؛ ويحوي تقرير JSON `items` و`count` و`parts` و`source_sha256` والتحذيرات. يرفض البرنامج الكتابة فوق أي ملف موجود أو الإخراج إلى الأصل. رمز الخروج 0 نجاح الاستخراج، و2 خطأ إدخال أو إخراج. النجاح لا يعني سلامة المستند علميًا.

المواضع محسوبة من صفر بوحدات Unicode في النص المستخرج لكل جزء XML؛ نهاية النطاق غير مشمولة. فاصل الفقرات سطر جديد، والتبويب محفوظ. ترقيم الفقرات من واحد داخل كل جزء ويشمل الجداول ومربعات النص. CSV يحوي صفًا لكل موضع، ونص التعليق ونص نطاقه في عمودين. إذا لم توجد نتائج يظهر صف no-items يوضح نطاق الفحص. تحمى الخلايا التي تبدأ بعلامة صيغة Excel بإضافة فاصلة عليا وتسجيل أسماء الأعمدة في escaped_fields؛ تبقى القيمة الحرفية الكاملة متاحة في JSON. لا يغيّر ذلك نص المستند.

## حدود النسخة
تقرأ المتن والحواشي والتعليقات الختامية والترويسات والتذييلات القياسية. لا تقرأ النص المصور أو الكائنات المضمنة وaltChunk، ولا تنفذ حقول Word أو روابط خارجية. يظهر تحذير عند التغييرات المتعقبة؛ النص المحذوف مستبعد والمدرج مقروء دون قبول أي تغيير. تُرفض XML أكبر من 40 MiB ومجموع XML أكبر من 160 MiB.
الإشارات الناقصة أو ذات النهاية اليتيمة تسجل بحالة خطأ، ولا يخمّن نص نطاقها. الإشارات النظامية التي تبدأ بشرطة سفلية مشمولة.

## الاختبارات
`python -m unittest discover -s tests -v`
تشمل حالات موجبة وسالبة، وسلامة بايتات الأصل، ونصًا عربيًا مشكولًا، ورفض الكتابة فوق الملفات. نتائج التنفيذ الموثقة في تقرير الحزمة؛ التوافق المثبت محليًا Python 3.12 على Windows، وليس اعتمادًا لكل منصات التشغيل.

## النسبة والمقارنة
صاحب الوظيفة المرجعية الدكتور سعود العقيل. هذا تنفيذ مستقل من وصف الوظيفة باستخدام OOXML، بلا نقل شفرته أو بياناته. المرجع الأصلي `frm11OthSelectBookmark.frm::UserForm_Activate`، والتفصيل في `references/origin.json`.
لم تظهر أداة تنفيذ بهذه الوظيفة المحددة ضمن 33 بطاقة مهارة في المستودع عند البصمة المذكورة. تتقاطع وظيفيًا مع تعليمات تحرير الكتب وحماية الإحالات؛ الأداة الحالية تنفيذ محدد للقراءة فقط يمكن استدعاؤه منها.
لا تنشر الحزمة أو ترفعها إلى GitHub قبل مراجعة المستخدم واعتمادها.
