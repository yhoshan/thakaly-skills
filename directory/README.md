# دليل المهارات والأدوات الخارجية

هذا القسم **دليل إحالة** وليس مستودعًا يملك الشفرات أو يشغل الخدمات المذكورة. نُوثق وظيفة كل خدمة وصلتها بالبحث الشرعي والعربي، ونحيل إلى المصدر الأصلي دون إعادة استضافة ملفاته أو نسخ وصفه حرفيًا.

- [أدوات العربية](arabi-tools.md) — تفريغ التسجيلات العربية.
- [كنوز — نقاية](nuqayah-kunuz.md) — دليل اكتشاف التطبيقات والمشروعات الإسلامية.
- [تفريغ — Tafrigh](tafrigh.md) — مشروع مفتوح المصدر لتفريغ الصوتيات والفيديو.

الروابط الخارجية لا تُعدّ جزءًا من مهارات ذكالي المستضافة؛ ووجود الأداة هنا لا يعني اختبارها أو ضمان استمرار الخدمة أو إعادة ترخيصها.
