# مهارات ذكالي — قرار الفصل والإغلاق v1.0 (25 أكتوبر 2026)

**قرار معتمد:** «مهارات ذكالي» منفصل إداريًا وتنفيذيًا عن «معيار ذكالي». لا يشترط اكتمال المعيار لإغلاق المهارات. المستودع خاص وغير مخصص للنشر.

## نتائج التحقق الفعلية
- أُعيد تشغيل مدقق المصدر والنسبة v0.2 محليًا: **8/8** اختبارات نجحت.
- أُعيد تشغيل كاشف منهج المؤلف v0.5 محليًا: **46/46** اختبارًا نجحت، لكنه لم يجتز القبول العلمي الشامل: TS-010 = **3/6**.
- أُعدّت حزمة محلية تضم نص المهارتين، الاختبارات، تعليمات التشغيل، بصمات SHA-256، ونتائج الاختبار.
- لم يثبت بعد تطابق شفرات التنفيذ في GitHub مع النسخ المحلية المختبرة؛ الموجود في GitHub قبل هذا التقرير ملفات تنظيم لا ملفات تنفيذ مطابقة.

## الجرد والاعتماد
وثق السجل السابق تسع مهارات محلية/تاريخية قبل إضافة «كاشف منهج المؤلف». بإضافته صار العدد **عشر مهارات ذات أسماء معلومة**، لكن **ليس عشر مهارات معتمدة**. سبع من التسع القديمة لم يجرِ إعادة التحقق التشغيلي منها اليوم، مع اختلاف مستوى أدلتها السابقة؛ والمدقق العلمي لـExcel لم يعاد اختباره اليوم.

## الحكم الآن
**قيد التنفيذ** — السبب الوحيد الخاص بالمهارتين المختبرتين: عدم الإيداع والمطابقة في GitHub. أما اختبار كاشف المنهج العلمي فهو *قيد استخدام معلن* وليس سببًا لعدم إغلاقه كأداة استخراج محدودة.

لا إعادة بناء، ولا إضافة مهارات، ولا ارتباط بإكمال المعيار، ولا نشر عام.
