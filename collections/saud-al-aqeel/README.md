# مهارات الدكتور سعود العقيل
**أدوات لخدمة الباحث العربي**

قسم علمي وتقني متخصص ضمن [مهارات ذكالي](../../README.md)، يُعنى بوظائف التحرير والمراجعة والأتمتة الواردة في دليل **«شرح برمجيات العقيل»**، وتحويل المختار منها إلى مهارات مستقلة قابلة للفحص والاستخدام.

> **النسبة والحقوق:** الدكتور سعود العقيل صاحب البرمجيات المرجعية. التنفيذات الجديدة مستقلة ومستلهمة من وظائف الدليل؛ لا تتضمن سورسه الأصلي أو قواعد بياناته إلا بإذن مستقل.

## المهارات الموجودة في المستودع

**12 بطاقة مهارة** تغطي النص العربي والتشكيل، وحواشي Word، والفهارس، والشعر، وعلامات صفحات الكتب التراثية.

- **تحرير النص:** [فواصل العربية](../../skills/arabic-punctuation-auditor/) (نموذج برمجي أولي محدود)، [تكرار التشكيل](../../skills/diacritic-anomaly-auditor/)، [ترتيب الحركات](../../skills/arabic-diacritic-order-auditor/)، [إحالات الآيات](../../skills/quran-citation-normalizer/).
- **الحواشي والتوثيق:** [الحواشي الفارغة](../../skills/empty-footnotes-auditor/)، [جرد الحواشي](../../skills/footnote-reference-inventory/)، [مرشحات المراجع](../../skills/footnote-source-candidates/).
- **الفهارس:** [التكرار](../../skills/index-entry-duplicate-auditor/)، [الترتيب](../../skills/index-entry-order-auditor/)، [فهرس الأعلام](../../skills/index-entry-review/).
- **الشعر والكتب:** [فواصل الأشطر](../../skills/poetry-hemistich-separator-auditor/)، [علامات صفحات الشاملة](../../skills/shamela-page-marker-audit/).

**حالة هذه المجموعة:** معظمها بطاقات تطوير تنتظر نقل البرامج والاختبارات المستقلة؛ لا يعني الرابط اكتمال تشغيل المهارة.

## الدفعة التالية — تم اختبارها خارج المستودع

جرد الإشارات المرجعية، واستخراج تعليقات المراجعين، وجمع المقاطع المظللة من ملفات DOCX. تلقت اختبارات برمجية في حزمة منفصلة، وما زال **الإيداع والمراجعة داخل المستودع** معلقين؛ لذلك لا تدخل في الـ12.

## ضوابط العمل

1. لكل مهارة وصف ومدخلات ومخرجات واختبارات، مع عدم تعديل الملف الأصلي.
2. توثيق موضع الوظيفة في مصدر الدكتور سعود مع التمييز بين الأصل والتطوير المستقل.
3. عدم نشر شفرات الدكتور سعود أو قوالبه أو بيانات Access دون إذن.
4. لا تُعلن الجاهزية العلمية اعتمادًا على نجاح الاختبار البرمجي وحده.
