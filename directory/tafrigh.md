# تفريغ — Tafrigh

- **المشروع الأصلي:** https://github.com/ieasybooks/tafrigh
- **الوظيفة:** مشروع برمجي لتفريغ الصوت والفيديو إلى نصوص.
- **فائدة الباحث:** إعداد مسودات من المحاضرات والتسجيلات، تمهيدًا للتحرير العلمي والفهرسة.
- **التصنيف:** مشروع خارجي؛ الرابط إلى المستودع الأصلي وليس نسخة من الشفرة.
- **الحالة:** إحالة فقط؛ لم نجرب بناء المشروع أو تشغيله ضمن مهارات ذكالي، ويجب مراجعة متطلباته وترخيص نسخته قبل الاستخدام.
