# معيار ومهارات ذكالي | Thakaly Standard & Skills

مستودع **خاص** لجمع المرجعية العلمية لمعيار ذكالي والمهارات التطبيقية المساندة له، مع الاختبارات وحدود الاعتماد.

> الحالة: تأسيس المستودع. **النص المرجعي الكامل المعتمد لمعيار ذكالي لم يُودع بعد**، ولا يجوز استبداله بملخص مستنتج.

## أقسام المشروع
- `standard/`: النص العلمي المعتمد للمكونات والقواعد (معلّق حتى وصول الأصل).
- `skills/`: المهارات العلمية والتنفيذية، بعد تدقيق حقوقها وشفراتها.
- `tests/`: عينات الاختبار وتقارير القبول والإخفاقات.
- `registry/`: سجل الجرد والإصدارات وحالة كل مهارة.
- `governance/`: سياسة التحقق والاعتماد والتحديث.

## قرارات ملزمة
1. المعيار أصل علمي حاكم، والمهارات أدوات لتنفيذه؛ لا تُعدّل قواعد المعيار لعجز أداة تقنية.
2. مدقق المصدر والنسبة v0.2: مقبول قبولًا مشروطًا لفحص البنية وقرائن النقل؛ لا يثبت صحة النسبة تاريخيًا.
3. كاشف منهج المؤلف v0.5: مغلق لهذه النسخة؛ صالح لاستخراج **شواهد مرشحة للمراجعة** فقط. اختبار القبول المستقل TS-010: **3 من 6**؛ لا يجوز استعماله للتكشيف الشامل أو الإدخال الآلي إلى مرقوم.
4. صفّاف والمدقق العلمي لـExcel: قبول أولي محدود، وليس اعتمادًا عامًا.
5. تراث مصدر البحث الأول، والشاملة مرجع تكميلي عند الحاجة، دون فتح ربط MCP مكرر.
6. لا تُرفع حزم الطرف الثالث أو ملفات فيها أسرار أو مواد مرخصة قبل فحص المصدر والحقوق.

## المتبقي قبل الإغلاق
- العثور على **النسخة الكاملة المعتمدة** من معيار ذكالي وإيداعها كما هي مع إثبات الإصدار.
- مراجعة الحزم الخاصة والمرشحة من جهة الأسرار والتراخيص.
- نقل الملفات المختبرة مع تقاريرها وسجل واضح لحالات الاعتماد.
