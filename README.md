# مهارات ذكالي | Thakaly Skills

**مهارات وأدوات رقمية لخدمة الباحث في العلوم الشرعية واللغة العربية**

مستودع يجمع المهارات القابلة لإعادة الاستخدام، وأدوات التدقيق والمعالجة البحثية، والدليل المنتقى للمشروعات الخارجية. غايته تحويل الأعمال المتكررة إلى خطوات موثقة يمكن تشغيلها وفحص نتائجها، مع حفظ النصوص والمصادر وحقوق أصحاب الأعمال.

> **المستودع حاليًا خاص وفي طور المراجعة.** المهارات متفاوتة الاكتمال، وليست كل بطاقة أداة قابلة للتشغيل. وتُراجع الإضافات والتعديلات قبل اعتمادها من **مشرف المستودع**.

## مهارات الدكتور سعود العقيل

**[مهارات الدكتور سعود العقيل — أدوات لخدمة الباحث العربي](collections/saud-al-aqeel/README.md)**

قسم خاص لتوثيق وتطوير الوظائف التي تخدم الباحث العربي، مستلهم من دليل **«شرح برمجيات العقيل»**. تُنسب البرمجيات الأصلية إلى الدكتور سعود العقيل، وتُميّز عنها التنفيذات المستقلة التي تُنشأ هنا؛ ولا تُنشر الشفرات الأصلية أو قواعد بياناتها دون إذن.

**البطاقات الحالية (12):**

- [فاحص الفواصل العربية](skills/arabic-punctuation-auditor/) — نموذج أولي محدود الوظيفة؛ لم تُستكمل اختبارات المستودع.
- [فاحص تكرار التشكيل](skills/diacritic-anomaly-auditor/)، [ترتيب الشدة والحركات](skills/arabic-diacritic-order-auditor/)، [توحيد إحالات الآيات](skills/quran-citation-normalizer/).
- [جرد إشارات الحواشي](skills/footnote-reference-inventory/)، [كشف الحواشي الفارغة](skills/empty-footnotes-auditor/)، [استخراج مرشحات المراجع](skills/footnote-source-candidates/).
- [فحص المداخل المكررة](skills/index-entry-duplicate-auditor/)، [ترتيب الفهارس](skills/index-entry-order-auditor/)، [مراجعة الأعلام](skills/index-entry-review/).
- [فحص فصل شطري البيت](skills/poetry-hemistich-separator-auditor/)، [علامات صفحات الشاملة](skills/shamela-page-marker-audit/).

**دفعة قيد المراجعة، ولم تُودع بعد:** جرد الإشارات المرجعية، واستخراج تعليقات المراجعين، وجمع المقاطع المظللة من Word. لذلك لا تدخل هذه المهارات الثلاث في الحصر الحالي.
