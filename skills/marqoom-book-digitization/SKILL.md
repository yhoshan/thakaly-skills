# مهارة مرقوم: رقمنة الكتب والكشافات الموسوعية

**الحالة: قيد الاختبار والتحكيم العلمي.** هذه مهارة استرجاع وترشيح، لا تدّعي تحقيق نسبة جميع النتائج إلى مؤلفيها.

## الغرض
تحويل النص الكامل لكتاب أو موسوعة إلى كشافات مترابطة قابلة للبحث والتحقق؛ مع حفظ المصدر والموضع، وفصل المؤلف عن صاحب المتن والناقل والمكمل والمحقق.

## مراحل التنفيذ
1. **فحص الأصل:** توثيق الصيغة والطبعة والبصمة SHA-256 ووحدات القراءة الفعلية والفجوات.
2. **ضبط الحدود:** تقسيم المصدر إلى نطاقات تحريرية دقيقة، وتحديد وحدة الفهرسة (صفحة نصية، ترجمة، أثر، مسألة). نطاق المؤلف **ليس إثباتًا لقائل كل جملة**.
3. **تصميم محاور علمية خاصة بالكتاب:** لا يفرض قالب واحد على موسوعات الفقه والحديث واللغة.
4. **استخراج شامل قابل للتكرار:** بحث إشاري مع معالجة التشكيل والاختلافات الكتابية؛ حفظ اللفظ الأصلي والسياق ومعرف الوحدة والإحداثيات.
5. **تحقيق النسبة والتصنيف:** تمييز كلام المؤلف من النقول والمتن المشروح والتكملات؛ ضبط الكتب والأعلام والحديث والمسائل والأحكام والضمائر.
6. **التحقق الكمي والنوعي:** إحصاء وحدات المصدر والمفحوص والمستبعد، وفحص تكرار المعرفات واتساق الأعداد والعينات السياقية.
7. **التسليم:** CSV/Excel مرجعي + JSON للاستخدام + تقرير تحقق؛ عدم إدخال البيانات إلى الموقع أو إرسال الأصول الخام إلى منفذ الواجهة قبل الاعتماد.

## التشغيل
```bash
python scripts/index_epub.py --input BOOK.epub --config config.json --out OUTPUT_DIR
python -m unittest discover -s tests -v
```
يلزم Python 3 و`beautifulsoup4`. يضم `references/config_example.json` مثال الحدود والمحاور؛ يضبط لكل كتاب على حدة.

## قواعد علمية غير قابلة للتجاوز
- ظهور «حديث صحيح» لا يثبت أن الحكم للمؤلف؛ يلزم تحديد قائل الحكم وقيده وسياقه.
- ظهور «قال المصنف» لا يثبت تعقبًا أو نقدًا للمتن المشروح.
- ظهور «وهو خطأ» لا يثبت أن المنتقد هو أبو ثور أو غيره دون تحليل عائد الضمير.
- ورود «وفي نسخة» لا يدل بذاته على نسخة المهذب؛ يجب تحديد النص المنسوخ والقراءة.
- ظهور «الراجح» قد يكون حكاية اختيار شخص آخر.
- الفوائد التربوية والمنهجية تحتاج قراءة السياق، ولا تختزل في الكلمات المفتاحية.
- الأسانيد تُرقمن وتُفهرس دون حكم آلي على صحتها أو ضعفها.
- تحفظ التهجئة الأصلية منفصلة عن الاسم أو العنوان الموحد؛ لا وصف للمصنف بأنه مفقود دون دليل مستقل.

## نموذج المجموع
انظر `references/AL_MAJMOU_METHOD.md`. اعتمد شرح النووي وتكملة السبكي فقط، واستبعد تكملة المطيعي. لا تُعمّم معرفات صفحات هذا الإصدار من EPUB على طبعات أخرى.

## حدود الصلاحية
تولد الأداة **مرشحات لفظية** في طبقة مستقلة عن النتائج العلمية المعتمدة. لا تعني كثرة التكرارات تعدد المسائل أو الكتب أو التراجم.

## معيار الإغلاق
نص أصلي موثق، ونطاقات مضبوطة، وسجلات ذات معرفات ومواضع قابلة للمراجعة، وفحص مستقل للعينات العلمية موزع على المحاور والمؤلفين، وإفصاح صريح عما لم يتحقق. لا يُعلن الكشاف محكمًا اعتمادًا على نجاح الاختبارات البرمجية وحدها.
